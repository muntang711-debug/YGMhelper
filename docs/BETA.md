# 회원 베타 운영

회원 자료는 `AUTH_DB` (`ygmhelper-members-beta`)에 저장하며 급식 평가 `DB`와 분리합니다. 정식 출시 때의 초기화는 별도 작업입니다. 2026-11-06 이메일 인증 전환 시 사용자의 요청으로 기존 회원 1개와 세션·시도 제한 기록을 초기화했습니다. 급식 평가 DB는 보존했습니다.

## 공개 범위

- 급식: 공개.
- 비회원 시간표: 공개 NEIS 주간 자료를 서버에서 반환하고 화면 아래쪽은 블러 처리.
- 회원 시간표: 컴시간 + NEIS 시험일 처리.
- 비회원은 블러를 제거해도 공개 NEIS 자료만 확인할 수 있고 컴시간 자료는 서버가 반환하지 않음.

## 설정

- `MEMBERSHIP_ENABLED`, `REGISTRATION_OPEN`, `BETA_MODE`: 베타 활성화.
- 운영 Turnstile hostname: `ygmhelper.xyz`. 로컬 widget과 별개.
- Secret `TURNSTILE_SECRET`, `NEIS_API_KEY`, `TEACHER_NAME_MAP`은 공개 저장소에 없음.
- 회원 DDL: `auth-migrations/`. 급식 DDL: `migrations/`.
- 만료 세션/메일 토큰/시도 제한 기록과 가입 후 24시간이 지난 미인증 계정은 5분마다 scheduled handler에서 정리.
- 신규 가입은 2026-11-06-email-beta 동의 버전과 정식 출시 초기화 동의를 요구.

## 정식 출시 전

문의 연락처는 support@ygmhelper.xyz이며 운영자 표시 정보 및 국외 이전 상세 고지가 아직 미정임을 처리방침에 표시합니다. 베타라는 이유로 법령 의무가 사라지는 것은 아니며 법령 준수 완료를 보증하지 않습니다.

초기화가 필요할 때 먼저 사용 중인 Worker가 올바른 AUTH_DB를 가리키는지 확인하고, 가입·인증을 닫은 다음 AUTH_DB의 계정·세션·로그인 시도 기록만 대상으로 별도 삭제/새 DB 전환을 수행합니다. 급식 DB를 삭제하거나 전체 프로젝트를 초기화하지 않습니다. Cloudflare 복구용 백업의 만료 기간은 별도로 고려합니다.

로컬 테스트 계정은 운영 DB로 이전하지 않습니다. 테스트 성공만으로 외부 보안 검토를 대신하지 않습니다.

회원 DB에 0002_email_auth.sql을 적용하고 운영 d1_migrations에 반영했다. 인증 토큰은 auth_tokens에 보관하며 비회원·미인증 계정에 컴시간 자료를 반환하지 않는다.

2026-11-07: 로그인 유지 미선택은 세션 쿠키(서버 최대 24시간/비활동 2시간), 선택은 최대 30일의 고정 만료 쿠키와 DB 세션을 사용한다. 가입 브라우저에 HttpOnly 인증 쿠키를 발급하고 메일 토큰에 그 해시를 연결한다. 같은 브라우저의 인증 링크는 자동 로그인하고, 다른 브라우저는 이메일만 인증한 뒤 비밀번호 로그인을 요구한다. 기존 토큰은 인증을 완료할 수 있으나 브라우저 연결 정보가 없어 자동 로그인하지 않는다. 인증·메일 발송·비밀번호 변경 완료는 각각 별도 화면으로 이동한다. 로그인 페이지에는 비밀번호 찾기만 표시하고 재발송은 메일 확인 화면의 도움말 안에 둔다.
