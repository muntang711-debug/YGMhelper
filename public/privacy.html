수집 항목과 목적

아이디, 이메일 주소, 복원할 수 없도록 해시한 비밀번호, 이메일 인증 여부, 가입 시각과 동의 버전을 수집합니다. 회원 식별·로그인·이메일 인증·비밀번호 재설정에 사용하며 실명과 생년월일은 수집하지 않습니다. 이메일 인증 전에는 로그인할 수 없습니다.

급식 맛 평가

평가 집계는 누구나 볼 수 있으며 등록은 학교 퀴즈를 통과한 회원만 할 수 있습니다. 학생 인증 여부와 통과 시각을 저장해 급식 평가 등록과 선생님 전체 이름 열람 권한을 확인합니다. 퀴즈 답안은 계정에 저장하지 않습니다. 계정당 인증 시도 횟수를 저장하며 총 5회 모두 틀리면 해당 계정의 추가 인증과 해당 IP의 신규 가입·추가 인증을 차단합니다. 차단 IP의 해시와 차단 시각은 반복 가입 방지를 위해 차단 해제 시까지 보관합니다. 관리자 작업은 작업 종류·대상 식별자·시각을 기록하며 90일 후 주기적으로 삭제합니다. 공인 IP를 공유하는 네트워크의 다른 이용자에게도 차단이 적용될 수 있습니다. 평가 날짜, 등급과 회원 식별자를 해시한 값을 저장해 계정당 하루 한 표를 유지합니다. 아이디와 이메일은 평가 화면에 공개하지 않으며 탈퇴 시 계정에 연결된 평가도 삭제합니다. 기존 익명 평가는 집계에 남아 있습니다.

로그인 유지와 보안

로그인 쿠키는 인증에만 사용합니다. 로그인 유지를 선택하지 않으면 브라우저 세션 쿠키를 사용하며 서버에서 최대 24시간, 비활동 2시간까지 허용합니다. 로그인 유지를 선택하면 최대 30일 유지됩니다. 이메일 인증을 가입한 브라우저에서 완료하면 세션 쿠키로 자동 로그인하며, 다른 브라우저에서는 비밀번호 로그인이 필요합니다. 과도한 로그인 시도를 막기 위해 IP와 아이디의 해시를 최대 약 20분간 보관하고 주기적으로 삭제합니다.

보관과 삭제

회원 정보와 인증 자료는 탈퇴 시 사용 중인 DB에서 삭제합니다. 인증 링크는 30분, 비밀번호 재설정 링크는 15분 동안 한 번만 사용할 수 있으며 서버에는 토큰의 해시만 저장합니다. 인증되지 않은 계정은 가입 후 24시간이 지나면 주기적으로 삭제합니다. 메일 재요청과 발송량을 제한합니다. 로그인 세션과 시도 제한 기록은 5분마다 만료 여부를 확인해 삭제합니다. Cloudflare의 복구용 백업에는 삭제 전 정보가 최대 30일 남을 수 있으며, 별도 사용하지 않습니다. 정식 출시 시 베타 회원 DB와 세션을 초기화합니다.

Cloudflare 처리와 국외 이전

Cloudflare Workers·D1을 통한 저장·처리, Turnstile 로봇 확인, Cloudflare Email Service를 통한 인증·보안 메일 발송을 사용합니다. 이메일 주소와 인증·재설정 링크가 메일 발송 및 수신 서비스에서 처리됩니다. 수탁 서비스는 Cloudflare, Inc.이며 회원 DB는 아시아태평양 지역에 저장되고 Workers와 Turnstile은 글로벌 네트워크에서 처리됩니다. 국외 이전의 상세 고지와 근거는 아직 검토 중입니다. Cloudflare 개인정보 처리방침을 참고해 주세요.

동의 거부와 권리

수집·이용 동의를 거부하면 회원가입을 할 수 없습니다. 급식은 가입 없이 이용할 수 있습니다. 계정 관리에서 가입 정보를 확인하고 비밀번호를 재입력해 탈퇴할 수 있습니다. 인증한 이메일로 비밀번호를 재설정할 수 있으며 재설정 시 모든 기존 로그인 세션을 해제합니다. 추가 권리행사 문의는 support@ygmhelper.xyz로 보내 주세요.
